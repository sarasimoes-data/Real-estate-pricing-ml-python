# Real-estate-pricing-ml-python

This project, developed as part of the Data Mining and Machine Learning course in the Master's in Data Analytics and Decision Support Systems, presents an end-to-end predictive modeling study on residential real estate prices in Portugal following the CRISP-DM framework.

The primary objective was to determine and quantify the structural and geographic drivers that influence property market valuations, comparing parametric and non-parametric machine learning approaches. Using a consolidated national dataset of over 33,000 property listings from Kaggle, the data preparation pipeline implemented extensive string cleaning, mapping dictionaries for textual tipologies, categorical encoding (One-Hot Encoding), outlier filtering, and logarithmic transformations to normalize price and area distributions and stabilize variance.

The modeling phase developed and compared a baseline Multiple Linear Regression against an optimized Decision Tree Regressor calibrated via 5-fold cross-validation grid search (max_depth = 7). The Multiple Linear Regression achieved an overall R^2 of 78.92% (MAE: €77,904), excelling in estimating standard residential market segments, while regional model segmentation highlighted substantial spatial heterogeneity across Portuguese districts (e.g., Setúbal R^2 = 0.53 vs. Lisboa R^2 = 0.21). Feature importance analysis from the Decision Tree identified Property Area (62%), Lisbon location (12%), and Porto location (8%) as the primary drivers of housing value, while also illustrating the non-linear valuation premiums and heteroscedastic error distributions characteristic of luxury properties.

Together, this project demonstrates end-to-end data science capabilities in Python (Pandas, Scikit-Learn, NumPy, Seaborn), structured exploratory data analysis, econometric modeling, and the ability to extract actionable business conclusions from complex tabular data.
